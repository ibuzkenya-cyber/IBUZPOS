# IBUZPOS SYSTEM

GitHub Pages package for IBUZPOS SYSTEM with a larger business logo positioned on the left side of the dashboard welcome panel.

## Publish
1. Upload all files in this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Open the URL GitHub Pages provides.

The uploaded logo is stored in the current browser's local storage and included in full JSON backups. It does not automatically sync to other devices. Back up business data before replacing an existing installation.
